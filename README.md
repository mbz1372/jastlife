# JASTLIFE Landing Page

## Run locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Upload this folder to GitHub, or import it directly into Vercel.
2. Framework should be detected as Next.js automatically.
3. Build command: `npm run build`
4. Output settings: default Next.js settings.

The page is bilingual (FA/EN) and responsive.
